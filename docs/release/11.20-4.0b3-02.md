# Calimocho engine 0.1120.4.2 (calimocho-11.20-4.0b3-02)

> If you can afford it, buy [CrossOver](https://www.codeweavers.com/crossover).
> CodeWeavers wrote most of the macOS Wine work this engine is built on,
> and CrossOver comes with support, which this engine does not.

Second Calimocho engine release for the Xode beta. It supersedes
[11.20-4.0b3-01](11.20-4.0b3-01.md), which was never published and
should not be distributed. It is a local, Developer ID signed build.
It is **not notarized** and **not published** yet: publication comes with
the Xode 0.11.4 beta after QA round 2
([ADR-0078](../ADR/0078-developer-id-signed-engine-release.md),
[ADR-0079](../ADR/0079-forza-opt-ins-in-the-general-engine.md)).

## Version

Version **`0.1120.4.2`** (owner's scheme, 2026-10-26):
`0.<Wine major+minor>.<Apple GPTK major>.<our build number>`.

- `1120`: Wine 11.20 (`VERSION` in the Wine source).
- `4`: Apple Game Porting Toolkit 4 (D3DMetal `CFBundleShortVersionString`
  `4.0b3` in the framework's `Info.plist`).
- `2`: Calimocho build 2. Any rebuild, including a new GPTK beta, bumps it.

The engine ID stays `calimocho-11.20-4.0b3-02` so that the exact
components are readable from the folder name. `VERSION` and
`calimocho-engine.json` carry `0.1120.4.2`. Source:
<https://github.com/WorkingPrinciple/calimocho>, tag
`engine-0.1120.4.2`.

## Graphics APIs

| API | Path in this engine |
|---|---|
| Direct3D 12, 11 and 10 (64-bit games) | Apple D3DMetal 4.0b3 (`d3d12`, `d3d11`, `d3d10`, `dxgi` from the Game Porting Toolkit) |
| Direct3D 9, 8 and DirectDraw, and 32-bit Direct3D 10/11 | Wine's own wined3d |
| Vulkan | MoltenVK 1.4.2 (private Metal API build, as in 170ca) |
| OpenGL | Wine's macOS OpenGL path |

DXVK and vkd3d-proton are not included. DXVK may come later.

## What changed since -01

- **Forza Horizon 6 opt-ins (owner decision).** Patches 0006-0013 are
  compiled in, but each Forza fix is off unless its flag is `1`.
  Every other title runs exactly the -01 code paths. The flags, the
  GPU identity, the d3d12 shim and the profile steps are in
  `calimocho-engine.json` under `opt_ins.fh6`; only Xode's FH6 profile
  sets them.
- **Highball tsshim** (`lib/wine/x86_64-windows/d3d12_tsshim.dll`,
  GPL-3.0, built from upstream commit `1512223f`). It is inactive
  unless a profile copies it into the prefix as `system32\d3d12.dll`.
  Apple's `d3d12.dll` is never modified.
- **Licences.** `LICENSE` and `COPYING.LIB` (LGPL-2.1) ship at the root.
  `licenses/` now also has every Wine `libs/` licence, all MoltenVK
  component licences (including SPIRV-Headers), xxHash, the FreeType
  licence election (FTL) and the tsshim source with GPL-3.0.
- `VERSION` file at the root, read by generic folder-engine importers.

1. After the prefix is created or updated for this engine, copy ${ENGINE_ROOT}/lib/wine/x86_64-windows/d3d12_tsshim.dll to <prefix>/drive_c/windows/system32/d3d12.dll.
2. Set HB_D3D12_REAL to Z: + ${ENGINE_ROOT}/lib/wine/x86_64-windows/d3d12.dll with backslashes.
3. Keep XODUS_PRIVATE_RUNTIME_COM_STA unset (runtime COM must stay MTA).

## Install

`~/Library/Application Support/Xode/Engines/calimocho-11.20-4.0b3-02/`,
next to -01 until Xode switches. Xode should download and unpack the
archive itself (no quarantine attribute). By hand:

```bash
mkdir -p "$HOME/Library/Application Support/Xode/Engines"
shasum -a 256 -c calimocho-11.20-4.0b3-02-macos.zip.sha256
ditto -x -k calimocho-11.20-4.0b3-02-macos.zip "$HOME/Library/Application Support/Xode/Engines/"
```

## Replacing an LGPL library

The LGPL lets you swap the LGPL libraries for your own builds. The
GnuTLS family, FreeType and every Wine module stay separate dynamic
libraries under `lib/wine/x86_64-unix/` and `lib/wine/*-windows/`.
Build your version, give it the same install name (`@rpath/<name>`),
sign it at least ad hoc (`codesign --force --sign - <file>`), and
replace the file. The executables are signed without library
validation, so a library with a different signature loads. This was
checked by replacing `libgnutls.30.dylib` with an ad-hoc signed build:
HTTPS still worked.
